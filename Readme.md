# 🚢 Titanic Survival Prediction

## Описание
ML модель которая предсказывает выжил ли пассажир на Титанике.
Проект сделан в рамках Kaggle соревнования.

## Технологии
- Python
- Pandas
- NumPy
- Scikit-learn (Random Forest)

## Результат
- Точность на тренировочных данных: 83%
- Точность на Kaggle: 73%

## Что сделано
- Очистка данных (пропущенные значения)
- Кодирование категориальных признаков
- Обучение модели Random Forest
- Отправка предсказаний на Kaggle
